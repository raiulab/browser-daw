# セキュリティ / Security

## 日本語

脆弱性を見つけた場合は、公開Issueへ詳細を書かず、GitHubのSecurity Advisoryから非公開で報告してください。

このアプリはローカルの静的ファイルとして使う設計です。信頼できないプロジェクト、MIDI、音声ファイルを開く場合は注意してください。ランチャーは専用ブラウザプロファイルを使いますが、OSネイティブのプラグインを実行する機能はありません。

## English

If you discover a vulnerability, report it privately through a GitHub Security Advisory instead of posting details in a public issue.

This application is designed to run as local static files. Use care when opening untrusted project, MIDI, or audio files. The launchers use a dedicated browser profile, and the application does not execute native OS plug-ins.
